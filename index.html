Copy and paste

      
Pick an icon above, copy the SVG or JSX, and drop it straight into your app. Ink follows currentColor unless a palette is applied.

      
<svg viewBox="0 0 24 24"
  stroke="currentColor"
  fill="none">
  …
</svg>

    

    

      
Run the engine

      
The engine is plain JavaScript with zero runtime dependencies. Copy js/core into your project and render any icon dynamically by id.

      
import { renderIcon }
  from './js/core/index.js';

const { svg } = renderIcon({
  id: 'arrow-left--v162',
  color: '#8B5E3C',
  size: 32,
});
